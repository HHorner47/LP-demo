## 1. サイトを自分のパソコンで表示する

### いちばん簡単な方法：ダブルクリック

1. `LPkamo` フォルダを開きます。
2. **`index.html` をダブルクリック**する。
3. ブラウザが開いて、サイトが表示される。

これで見た目の確認ができる。
VSCの拡張機能でliveserverを導入しそこ経由で起動すると変更が即座に反映されるため便利

### 文章や写真を変えたあとは

ファイルを保存したら、ブラウザで **再読み込み** をすると変更が反映される。

変更が反映されないときは、**強制再読み込み**を試して。

- Windows：`Ctrl` + `Shift` + `R`
- Mac：`command` + `shift` + `R`

### スマホでの見え方を確認したいとき（Chrome）

1. サイトを開いた状態で、キーボードの `F12`（Mac は `command` + `option` + `I`）を押す。
2. 出てきた画面の左上にある、スマホとタブレットの形のアイコンを押す。
3. 画面がスマホの幅になります。もう一度 `F12` で元に戻る。

## 2. 文章を変える

### 基本の手順

1. VS Code を開き、メニューの「ファイル」→「フォルダーを開く」で `LPkamo` フォルダを選ぶ。
2. 左の一覧から **`index.html`** をクリックして開く。
3. 変えたい文章を探します。**`Ctrl` + `F`（Mac は `command` + `F`）** を押すと検索窓が出るので、変えたい言葉の一部を入力すると、その場所に飛べる。
4. 文章を書きかえる。
5. **`Ctrl` + `S`（Mac は `command` + `S`）で保存**する。(これまたVSCの設定で自動保存を変更してると勝手にされて便利)
6. ブラウザを再読み込みして確認する。

### よく変える文章の場所

検索窓（`Ctrl` + `F`）に、表の「検索する言葉」を入れると見つかります。

| 変えたいもの | 検索する言葉 | 注意 |
| --- | --- | --- |
| お店の紹介文（いちばん上） | `旬の九州 よかは、` | |
| 大きなキャッチコピー | `九州の旬を` | **3か所**あります（下で説明） |
| 「想い」の文章 | `包丁ひとつで` | |
| お品書きの紹介文 | `お造りから焼き物` | 料理そのものは [4章](#4-お品書き料理を変える増やす) へ |
| 「お飲み物」の文章 | `九州の地酒` | |
| 「空間」の文章 | `おひとりで` など | |
| 営業時間・定休日 | `17:00` / `定休日` | **複数か所**あります（下で説明） |
| 電話番号 | `1724` | **複数か所**あります（下で説明） |
| 住所 | `日吉町` | **複数か所**あります（下で説明） |
| アクセス・駐車場・お支払い | `徒歩10分` / `駐車場` / `VISA` | |
| Instagram・LINE のリンク | `instagram.com` / `lin.ee` | `href="…"` の `"` の間のURLを入れかえる |
| 検索結果に出るタイトル・説明 | ファイルのいちばん上（7〜8行目あたり） | `<title>` と `description` |

### 同じ情報が何か所にもあるもの

電話番号・営業時間・住所などは、ページのあちこちに載っています。**1か所だけ変えると、ほかの場所と食い違ってしまいます。**

VS Code の **「すべて置換」** を使うと、まとめて変えられて便利です。

1. `Ctrl` + `H`（Mac は `command` + `option` + `F`）を押します。
2. 上の欄に **今の言葉**、下の欄に **新しい言葉** を入れます。
3. 右側の「すべて置換」ボタン（または `Ctrl` + `Alt` + `Enter`）を押します。
4. 保存します。

#### 電話番号を変える場合

電話番号は2つの書き方で入っています。**両方とも**置換してください。

| 置換する前 | 置換した後（例：092-123-4567 の場合） | 意味 |
| --- | --- | --- |
| `050-1724-7878` | `092-123-4567` | 画面に表示される番号 |
| `05017247878` | `0921234567` | 押したときに電話がかかる番号（ハイフンなし） |

#### 営業時間・定休日を変える場合

次の文字を、それぞれ「すべて置換」してください（どちらも **3か所** にあります）。

- `月・火・木・金・土 17:00 – 23:00`
- `水曜日・日曜日・1月1日`

ラストオーダー（`L.O. 料理 22:00 / ドリンク 22:30`）は1か所だけです。

#### キャッチコピー「九州の旬を、ひと皿ずつ。」を変える場合

一文字ずつ浮かび上がる演出のため、次のように **3か所** に書かれています。

```html
<span class="sr-only">九州の旬を、ひと皿ずつ。</span>
<span aria-hidden="true" class="block" data-chars="九州の旬を、"></span>
<span aria-hidden="true" class="block lg:mt-24" data-chars="ひと皿ずつ。"></span>
```

- 1行目：文章全体（目の不自由な方の読み上げ用）
- 2行目：1行目に表示される文字（`data-chars="` と `"` の間）
- 3行目：2行目に表示される文字（`data-chars="` と `"` の間）

3つとも同じ内容になるように変えてください。

#### 住所を変える場合

住所の文字は「すべて置換」で変えられます。ただし、地図のリンクの中にも住所が入っています。地図用の部分は記号（`%E7%A6%8F…`）に変換されているため、検索しても見つかりません。

地図も直す場合は、`maps` で検索して出てくる次の部分を書きかえます。

- `query=` のうしろから `"` の手前まで
- `q=` のうしろから `"` の手前まで

記号の部分を消して、**新しい住所をそのまま日本語で**書けば動きます。

```html
<!-- 例 -->
href="https://www.google.com/maps/search/?api=1&amp;query=福岡県久留米市○○町1-2"
```

### フッターの年（© 2026）

自動で今年の年に変わるので、変える必要はありません。

## 3. 写真を入れ替える

### 大事なルール

このサイトでは、表示する画面の大きさ（スマホ・パソコン）に合わせて、**1枚の写真を3つの大きさで用意**しています。

| ファイル名の例 | 横幅 | どこで使われるか |
| --- | --- | --- |
| `sashimi-400.webp` | 400ピクセル | スマホなど小さい画面 |
| `sashimi-800.webp` | 800ピクセル | 中くらいの画面 |
| `sashimi-1600.webp` | 1600ピクセル | パソコンなど大きい画面 |

- 形式は **WebP（ウェッピー）**（ファイル名の最後が `.webp`）です。
- 写真の形は **横長（横3：縦2）** を基本にしてください。デジカメやスマホを横向きにして撮った写真ならだいたいこの比率です。
  - 表示する場所に合わせて、写真の端が自動で切り取られます。大事なもの（料理など）は **写真のまん中** に写るようにしてください。

### いちばん簡単な方法：同じ名前で上書きする

今ある写真と **まったく同じファイル名** の写真を作って上書きすれば、`index.html` を触らずに写真が変わります。

#### 手順

**① 入れ替えたい写真のファイル名を調べる**

ブラウザでサイトを開き、変えたい写真の上で **右クリック →「画像を新しいタブで開く」** を選びます。アドレス欄の最後に `images/food/sashimi-1600.webp` のようにファイル名が出ます。

**② 新しい写真を3つの大きさの WebP に変換する**

無料のサイト **Squoosh（スクワッシュ）** を使います。インストールは不要です。

1. https://squoosh.app/ を開きます。
2. 新しい写真を画面にドラッグして入れます。
3. 右側の設定を次のようにします。
   - **Resize（リサイズ）** をオンにして、**Width（幅）に `1600`** を入れる（Height は自動で決まります）
   - **Compress（圧縮）** で **`WebP`** を選ぶ
   - **Quality（画質）** は `75` 前後
4. 右下のダウンロードボタンを押して保存します。
5. 同じ写真で、Width を **`800`**、**`400`** に変えて、あと2回保存します。

**③ ファイル名をそろえる**

保存した3つのファイルの名前を、①で調べた名前に変えます。

```
sashimi-400.webp
sashimi-800.webp
sashimi-1600.webp
```

> Windows で拡張子（`.webp`）が見えない場合は、エクスプローラーの「表示」→「ファイル名拡張子」にチェックを入れてください。

**④ images フォルダに上書きする**

3つのファイルを、元の写真があったフォルダ（例：`images/food/`）に入れ、「置き換える」を選びます。

**⑤ ブラウザで確認する**

強制再読み込み（`Ctrl` + `Shift` + `R`）で確認します。

> **上書きする前に、元の写真をどこかにコピーしておく**と、元に戻したいときに安心です。

### 写真の説明文（alt）も変えましょう

写真には、目の不自由な方の読み上げや、写真が表示できないとき用の **説明文** がついています。写真の中身が変わったら、説明文も直してください。

`index.html` で写真のファイル名（例：`drink/shochu`）を検索すると、次のような行が見つかります。

```html
<img data-photo="drink/shochu" ... alt="焼酎の一升瓶を背景に、徳利と猪口、小皿を並べたカウンター" ...>
```

`alt="` と `"` の間を、新しい写真の内容に合わせて書きかえます。

> お品書きの料理写真の説明文は `js/main.js` にあります（[4章](#4-お品書き料理を変える増やす)）。

### 別の名前の写真に差し替えたい場合

`index.html` の中で `data-photo="フォルダ名/ファイル名"` という書き方をしています。**`-400.webp` などの最後の部分は書きません。**

```html
<img data-photo="space/counter" ...>
<!--   ↓ images/space/new-photo-400.webp, -800.webp, -1600.webp を用意した場合 -->
<img data-photo="space/new-photo" ...>
```

ファイル名には **半角の英数字とハイフン（-）だけ** を使ってください（日本語やスペースは使わないでください）。

### いちばん上の大きな写真（ファーストビュー）について

ページを開いて最初に出る写真は、**4枚が順番に切り替わる**スライドショーです。

| 順番 | 写真 | 変え方 |
| --- | --- | --- |
| 1枚目 | `images/hero/table-spread-…` | 下の説明を参照 |
| 2枚目 | `concept/sake-pour` | `index.html` の `hero-slide` と書かれた行の `data-photo` |
| 3枚目 | `space/counter` | 同上 |
| 4枚目 | `shop/entrance` | 同上 |

1枚目だけは表示を速くするため、書き方が違います。上書きで変えるのがいちばん簡単ですが、別の名前にする場合は `index.html` で `hero/table-spread` を検索し、出てくる **4か所**（`src` に1か所、`srcset` に3か所）をすべて書きかえてください。

### SNS で共有したときの画像（ogp.jpg）

LINE や Facebook などでサイトのURLを送ったときに出る画像です。

- ファイル：`images/ogp.jpg`
- 大きさ：**横1200 × 縦630 ピクセル**、形式は **JPG**
- 同じ名前で上書きすれば変わります（Squoosh で `MozJPEG` を選ぶと JPG で保存できます）。

## 4. お品書き（料理）を変える・増やす

お品書きの料理は **`js/main.js`** に、1品1行で書かれています。VS Code で `js/main.js` を開き、`お品書きのデータ` という見出しのすぐ下を見てください。

```js
const dishes = [
    { key: 'sashimi', photo: 'food/sashimi', name: 'お造り', alt: '鮪と白身魚のお造り。大葉と花穂じそを添えて', text: 'その日に仕入れた鮮魚を、魚ごとに厚みを変えて引きます。' },
    { key: 'sanma', photo: 'food/sanma', name: '秋刀魚の塩焼き', alt: '…', text: '…' },
    ...
];
```

### 1行の中身

| 項目 | 意味 | 例 |
| --- | --- | --- |
| `key` | 料理の識別名。**半角英数字**で、ほかの料理と重ならないもの | `'sashimi'` |
| `photo` | 写真の場所（`images/` と `-400.webp` などを除いた部分） | `'food/sashimi'` |
| `name` | 料理名（縦書きのお品書きと写真の下に出ます） | `'お造り'` |
| `alt` | 写真の説明文（読み上げ用） | `'鮪と白身魚のお造り…'` |
| `text` | 写真の下に出る料理の説明 | `'その日に仕入れた鮮魚を…'` |

### 料理名や説明を変える

`'` （半角のシングルクォーテーション）と `'` の間の日本語だけを書きかえます。

```js
name: 'お造り',
//      ↓
name: '本日のお造り',
```

### 料理を増やす

1. 料理の写真を3つの大きさで用意し、`images/food/` に入れます（[3章](#3-写真を入れ替える)参照）。例：`karaage-400.webp` / `karaage-800.webp` / `karaage-1600.webp`
2. 既存の1行をまるごとコピーして、すぐ下に貼りつけます。
3. 貼りつけた行の中身を書きかえます。

```js
    { key: 'karaage', photo: 'food/karaage', name: '鶏の唐揚げ', alt: '皿に盛った鶏の唐揚げとレモン', text: '外はかりっと、中はじゅわっと。' },
```

4. 保存して、ブラウザで確認します。

**行の順番がそのまま、お品書きの並び順**になります（いちばん上の行が、縦書きの右端・最初に表示される料理）。

### 料理を減らす

その料理の行を **1行まるごと** 削除します。

### 書きかえるときの注意（ここで失敗しやすいです）

- `'` は **半角** です。全角の `’` にすると動かなくなります。
- 文章の中に `'` を使いたいときは、代わりに全角の `’` や「」を使ってください。
- 各行の **最後のカンマ（`},`）** を消さないでください。
- `{` で始まり `},` で終わる形を崩さないでください。

> 書きかえたあと **お品書きの部分が丸ごと表示されなくなった** ら、上のどれかが原因です。VS Code では、間違いがある場所に **赤い波線** が出るので、目印にしてください。

## 5. 困ったときは

### うまく表示されない・崩れた

| 症状 | 考えられる原因と対処 |
| --- | --- |
| 変更が反映されない | 保存したか確認（VS Code のタブに `●` が出ていたら未保存）。強制再読み込み（`Ctrl` + `Shift` + `R`）を試す |
| 写真が出ない（枠だけ・空白） | ファイル名のつづり、`-400` / `-800` / `-1600` の3つがそろっているか、フォルダの場所、拡張子が `.webp` かを確認 |
| デザインが全部くずれて、文字だけ並んでいる | インターネットにつながっているか確認（デザインの仕組みをネットから読み込んでいます） |
| お品書きが丸ごと消えた | `js/main.js` の書き方の間違い（[4章の注意](#書きかえるときの注意ここで失敗しやすいです)） |
| ページの一部が消えた・レイアウトがずれた | `index.html` で `<` `>` の部分を消してしまった可能性。下の「元に戻す」を試す |

### 元に戻したい

- VS Code で **`Ctrl` + `Z`（Mac は `command` + `Z`）** を押すと、ひとつ前の状態に戻ります。何回か押せば、さらに前に戻れます。(ctrl + y で逆にも行ける)
- **作業の前に `LPkamo` フォルダをまるごとコピーしておく**のがいちばん安全です。困ったときは、コピーしておいたファイルと入れかえてください。

> 現在 `index.html` には `<meta name="robots" content="noindex, nofollow">` という設定があり、**Google などの検索結果に出ないように**なっています。本番で公開するときは、担当者にこの行を消してもらってください。
